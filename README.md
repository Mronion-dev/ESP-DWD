# DWDC — Double Wobble Drone

**DWDC (Double Wobble Drone Controller)** is an open-source budget drone project that includes:

- Semi-Complete drone-side code
- 3D printable files for the drone frame and mounting parts `needs improvment`
- (almost) All required design files to build the project from scratch `Not Done`

The goal of this project is to provide a simple and affordable drone platform that anyone can build at home using worldwide available components.

---
## Required Parts for the Drone
|Part|amount|
|----|------|
|ESP32-Microcontroller|1|
|BLDCs|2|
|SG90 Servos|2|
|MPU9250-IMU|1|
|LM2596-VoltageRegulator|1|
|2S or 3S Lipo battery|1|

### Notes

- signal interference sucks, just manage your cables man
- capacitors are recommended (47uF 10V+) but not needed 

---

## Features

- Low-cost design using world-wide hobby components, ~$52 in Lebanon, *prices will vary between countries*.
- Stabilization support through an I2C gyroscope/IMU (*to be implemented*)
- Fully 3D-printable structure

---

## Project Goal

The purpose of DWDC is to make drone building accessible to hobbyists, students, and makers without breaking the bank on some 500 dollar drone that doesn't even come with a controller.
